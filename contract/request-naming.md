# 요청 파일 이름 규칙 (약속 v1 · PC9 · 2026-11-17)

## 이름
```
<칸ID>_<시각>_<설명>.<확장자>
```
| 부분 | 규칙 | 예 |
|---|---|---|
| 칸ID | 대장의 칸 ID(`P01-01`) | P01-01 |
| 시각 | 한국 시각 `YYYYMMDD-HHMM` (같은 칸에 여러 번 넣어도 겹치지 않게) | 20261118-1430 |
| 설명 | 한글 · 영문 · 숫자 · `-`만 · 띄어쓰기 대신 `-` · 30자까지 | 홈첫화면-새렌더 |
| 확장자 | 이미지 `jpg` · `png` · `webp` / 영상 `mp4` | jpg |

- 예: `P01-01_20261118-1430_홈첫화면-새렌더.jpg`
- 모바일 그림을 따로 줄 때(대장 "모바일 파일 따로" 칸만): 설명 끝에 `-모바일` → `P01-02_20261118-1431_그대카드-모바일.jpg`
- 영상: 같은 이름으로 첫 화면 그림을 함께 → `…_홈영상.mp4` + `…_홈영상-포스터.jpg`
- 메모: 같은 이름 `.txt`(손으로 넣을 때) · 스튜디오 "확정"은 같은 이름 `.json`(아래)

## 스튜디오 "확정" 때 같이 만드는 파일 `<같은 이름>.json`
```json
{
  "version": 1,
  "key": "home.hero",
  "slotId": "P01-01",
  "media": "image",
  "files": { "pc": "P01-01_20261118-1430_홈첫화면-새렌더.jpg" },
  "license": "자체 렌더",
  "ai": false,
  "altKo": null,
  "note": "반지가 오른쪽에 보이게",
  "focus": { "x": 0.72, "y": 0.5 },
  "machine": "데스크톱",
  "requestedAt": "2026-11-18T14:30:00+09:00"
}
```
- `files`에는 `pc` · `mobile` · `poster` 중 있는 것만
- `focus`(약속 v1.3 · 있을 때만): 미리보기에서 고른 "꼭 보여야 할 점"(0~1 · 왼쪽 위 = 0,0) → M5가 휴대폰 파일을 이 점 둘레로 자름(휴대폰 파일이 따로 있는 칸) · 한 파일 칸은 `content/media.ts`의 `focus: 'x y'`로 적음 · 없으면 가운데
- 손으로 넣은 요청(.txt만)도 M5가 그대로 처리함
- `targetPR`(v1.6 · PC2-스튜디오-7 · 수정안에서 확정했을 때만): `{ "id": "pr-101", "number": 101, "branch": "pc1/hero", "sha": "<그때 커밋>" }` · 이름은 `<칸ID>_<시각>_pr101_<설명>` → M5는 이 요청을 **`--target-pr 101`일 때만** 처리해 그 PR 브랜치에 커밋(새 PR 아님) · **브랜치는 GitHub(`gh pr view`)에서 얻음**(.json branch · sha는 비교용 · 다르면 멈춤 · 열린 PR · main/기본/base 아님 · 확정 뒤 PR에 새 커밋이면 "확인 필요" → `--accept-new-head` · 되감기 없음 · PC2-스튜디오-8) · targetPR 없는 요청(공개본)은 지금처럼 main에서 새 브랜치
- `target`(v1.7 · PC2-스튜디오-9 · 영상 요청만): `"both" | "mobile" | "pc"` — 놓을 때 고른(또는 "알아서"로 정해진 · 세로 영상 = `mobile`) 화면. 지금 M5는 영상을 사이트에 넣지 않음(히어로 영상은 PC1 일) → 넣을 때 휴대폰 영상 · PC 영상 자리를 고르는 데 씀 · 없으면 `both`

## 폴더 흐름
| 폴더 | 누가 | 언제 |
|---|---|---|
| `요청\` | 사용자 · 스튜디오 "확정" | 새 그림을 넣을 때 |
| `작업중\` | PC9(M5) | 처리 시작 때 옮김 |
| `이전\<key>\` | PC9(M5) | 교체 전 원래 파일 보관 · 칸마다 최근 2개 판(더 오래된 것은 `_보관\`) |
| `완료\` | PC9(M5) | 공개된 뒤 요청 파일을 옮김 |
| `_시험\` | 스튜디오 | 놓아 본 시험 그림(공개 안 됨) |
| `_상태\<key>.json` | 스튜디오 · PC9 | 칸 상태(status.schema.json) |

## 금지
- 파일 이름에 손님 이름 · 전화번호 등 개인정보 쓰지 않음
- 큰 원본(.blend · EXR · 영상 원본)은 넣지 않음(Synology 원래 자리)
